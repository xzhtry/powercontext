# 周边去哪儿：基于高德的地点推荐助手

本目录是 2026 PowerContext 生态赛题「周边去哪儿」的参赛资产。核心交付物是 [`SKILL.md`](SKILL.md)：一个由评测平台加载的轻量 Skill，指导 Agent 用高德 MCP 完成“一句话需求 → 地点搜索 → 步行路线 → 筛选推荐”的单轮任务。

## 文件

| 文件 | 说明 |
| --- | --- |
| `SKILL.md` | 唯一需要上传到提测平台的 Skill 文件；包含需求解析、工具调用、筛选排序、回答格式和异常处理。 |

## 依赖的高德 MCP 工具

| 用途 | 工具 |
| --- | --- |
| 起点解析（地名/地铁站 → 坐标） | `maps_geo` |
| 周边搜索（主路径） | `maps_around_search` |
| 关键词搜索（兜底/补充） | `maps_text_search` |
| 地点详情（补坐标/地址） | `maps_search_detail` |
| 步行路线 | `maps_direction_walking` |

Skill 不包含 API Key、服务地址或任何密钥；运行环境和工具由评测平台统一配置。

## 关键设计

- **起点唯一**：所有推荐都从用户给的同一个起点出发，不拼多站行程。
- **路线时间为准**：步行距离和时间只读取 `maps_direction_walking` 的 `route.paths[0]`；禁止用直线距离或搜索结果的 `distance` 估算。
- **硬条件严格过滤**：地点类型、步行时间上限、距离上限、数量逐条检查；超限地点不进入推荐表。
- **最多 3 个**：用户要求更多时按 3 个给出并说明；不足时如实说明原因并给放宽建议。
- **数据可追溯**：名称、地址逐字使用工具返回值；搜索接口不返回坐标时，先调用 `maps_search_detail` 补 `location`，再查步行路线。
- **不编造**：安静程度、排队情况、营业状态等无数据支撑的信息标注“未核实”；查询失败和无结果区分处理。
- **一次回答**：除起点无法解析外不追问；缺省信息按 Skill 中的默认值处理并说明假设。
